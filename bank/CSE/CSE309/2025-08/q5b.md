Consider below a 'C' code fragment and the corresponding assembly code generated by some 'gcc' compiler using $-$O2 optimization switch. Now, identify and explain the optimizations that have been performed by the compiler for the given 'C' code. Will the same optimization be performed if the array 'arr[10]' is declared as a global variable? Justify your answer.

**Program written in C**

```c
#include<stdio.h>
int main() {
  int arr[10];
  int n;
  scanf("%d",&n);
  for (int i=0; i<n-1;i++){
    for (int j=0; j<n-i-1; j++){
      if (arr[j] > arr[j+1]){
        int temp = arr[j];
        arr[j]=arr[j+1];
        arr[j+1]=temp;
      }
    }
  }
  return 0;
}
```

**Assembly code generated by gcc**

```text
.LC0:
        .string "%d"
"main":
        sub     rsp, 24
        mov     edi, OFFSET FLAT:.LC0
        xor     eax, eax
        lea     rsi, [rsp+12]
        call    __isoc99_scanf
        xor     eax, eax
        add     rsp, 24
        ret
```
