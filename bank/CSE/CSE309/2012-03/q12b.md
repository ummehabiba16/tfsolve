The following C code computes Fibonacci numbers recursively.

```c
int f ( int n) {
    int t, s;
    if ( n < 2 ) return 1;
    s = f (n - 1) ;
    t = f (n - 2) ;
    return s + t ;
}
```

(i) Show the complete activation tree for it.

(ii) What does the control stack look like when the fourth call of f (1) is about to return. Show only argument and return value in an activation record. (Assume that the initial call is f(6)).
