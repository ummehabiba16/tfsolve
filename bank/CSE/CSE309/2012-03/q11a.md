The following grammar generates binary numbers with a decimal point.

$$A \to L\ .\ L \mid L$$

$$L \to L\ B \mid B$$

$$B \to 0 \mid 1$$

(i) Design an SDT (**Syntax-directed translation scheme**) that computes the value of binary numbers generated from the above grammar.

(ii) The translation of string 110.101 should be the decimal number 6.625. Draw the annotated parse tree for this translation and clearly show the dependency graph.
