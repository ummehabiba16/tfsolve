For the following assignment statement write down an equivalent three address code sequence.

$$y[i][j] = a[k] * b + c\,(3, d, 2.5)$$

Here, $y$ is an array of type $\textbf{array (10, array (15, float))}$, $a$ is an array of type $\textbf{array (10, integer)}$ and $c$ is a function of type $\textbf{integer} \times \textbf{float} \times \textbf{float} \to \textbf{float}$. Assume that width of an integer is 4 and that of a float is 8.
