Below is an SDT for generating three-address code for array references. What will be the three-address code for the expression `a[b[i]][c[j]]` generated by the given SDT? Assume that the arrays a, b and c are declared as, **int** `a[5][5], b[3], c[3]` and types and widths of the arrays have correctly been saved in the symbol table. The attributes associated with the terminals and nonterminals have their usual meanings. Make other justified assumptions as required.

```text
L -> id [ E ]     { L.array = top.get(id.lexeme);
                    L.type = L.array.type.elem;
                    L.addr = new Temp();
                    gen( L.addr '=' E.addr '*' L.type.width); }

   | L1 [ E ]     { L.array = L1.array;
                    L.type = L1.type.elem;
                    t = new Temp();
                    L.addr = new Temp();
                    gen( t '=' E.addr '*' L.type.width);
                    gen( L.addr '=' L1.addr '+' t); }

E -> id           { E.addr = top.get(id.lexeme); }

   | L            { E.addr = new Temp();
                    gen( E.addr '=' L.array.base '[' L.addr ']'); }
```
