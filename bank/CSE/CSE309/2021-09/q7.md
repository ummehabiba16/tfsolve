In carrying out nonrecursive predictive parsing for an input string $w$ and a parsing table $M$, if $X$ is the top stack symbol, $a$ is the current input symbol, and $M[X, a] = X \to Y_1 Y_2 \ldots Y_k$, the following actions are carried out,

(i) output the production $X \to Y_1 Y_2 \ldots Y_k$,

(ii) pop the stack,

(iii) push $Y_k, Y_{k-1}, \ldots, Y_2, Y_1$ onto the stack, with $Y_1$ on top.

Explain with necessary figures and justifications, how the actions above correspond to top-down left-most derivation.
