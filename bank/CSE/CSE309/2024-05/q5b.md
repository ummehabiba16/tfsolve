Consider a 'C' code fragment and the corresponding assembly code generated by some 'gcc' compiler using $-$O2 optimization switch. Now, identify and expain the optimizations that have been performed by the compiler for the given 'C' code.

**Program written in C**

```c
#include<stdio.h>
int a[50], b[50],x,y,z,k,n;
int factorial(int n)
{
    int fact;
    for(int i=n;i>=0; i--)
        fact=fact*i;
    return fact;
}
int main(){
    int t;
    t=y;
    y=z;
    z=t;
    x=y^y;
    if(x) n=10;
    else n=20;
    k=factorial(n);
    for (int j=0;j<50;j++)
        for(int i=0;i<100;i++)
            a[j]*=b[j];
    return 0;
    for (int i=0;i<50;i++)
        a[i]=b[i];
}
```

