**Choice of values** (assumption: system clock 1 MHz, the paper's default)

- Fast PWM with **WGM13:10 = 1110**: TCNT1 counts 0 $\to$ ICR1 and restarts, so **ICR1 sets the period** and **OCR1A sets the high time**.
- No prescaler: 1 tick = 1 µs. Period 2000 µs = 2000 ticks, high time 300 µs = 300 ticks.
- The counter goes through TOP + 1 values per period, so **ICR1 = 2000 $-$ 1 = 1999** and **OCR1A = 300 $-$ 1 = 299** (as corrected on slide 57).
- **COM1A1:COM1A0 = 10** (Table 3): OC1A is **set at BOTTOM** and **cleared on compare match**, so it is high from 0 to OCR1A.

| Register | Value | Bits |
|:--|:--|:--|
| TCCR1A | 0b10000010 | COM1A1:0 = 10, COM1B1:0 = 00, WGM11:10 = 10 |
| TCCR1B | 0b00011001 | ICNC1 = ICES1 = 0, WGM13:12 = 11, CS12:10 = 001 (no prescaler) |
| ICR1 | 1999 | period 2000 µs |
| OCR1A | 299 | high time 300 µs |

**Code**

```c
#include <avr/io.h>

int main(void)
{
    DDRD |= (1 << PD5);        // OC1A (PD5) as output

    ICR1  = 1999;              // TOP: period = 2000 ticks = 2000 us
    OCR1A = 299;               // high time = 300 ticks = 300 us

    TCCR1A = 0b10000010;       // COM1A = 10 (clear on match, set at BOTTOM), WGM11:10 = 10
    TCCR1B = 0b00011001;       // WGM13:12 = 11: mode 1110 (Fast PWM, TOP = ICR1), clk/1

    while (1);                 // waveform is generated by hardware
}
```
