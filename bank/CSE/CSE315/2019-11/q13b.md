Suppose you wrote a code to measure elapsed time of a code segment. At the beginning of the code segment, you have reset TCNT1. During the execution of the code segment, TIMER1 overflow interrupt was triggered 50 times. After execution of the code segment TCNT1 value was 1200. What was the elapsed time in seconds? (TIMER1 Prescaler is 8)
