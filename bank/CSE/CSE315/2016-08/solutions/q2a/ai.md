**Types of interrupts in the 8086**

1. **Hardware (external) interrupts:**
   - **NMI** (non-maskable, pin 17): rising edge, cannot be disabled, always type 2.
   - **INTR** (maskable, pin 18): level, accepted only when IF = 1; the type number (0-255) is supplied by the device during $\overline{INTA}$.
2. **Software interrupts:** the instruction `INT n` (n = 0-255) calls the ISR of type n.
3. **Internal / predefined (exceptions):** generated by the processor itself as a result of executing an instruction (divide error, single step, overflow).

The ISR addresses are in the **interrupt vector table** at 00000H-003FFH: 4 bytes per type (IP low word, CS high word); types 0-4 are dedicated, 5-31 reserved by Intel, 32-255 available to users.

**Interrupts predefined by Intel**

| Type | Name | Cause | Vector at |
|:-:|:--|:--|:--|
| 0 | Divide error | DIV/IDIV quotient too large (or divide by 0), e.g. AX = 4000H / BL = 02H gives 2000H, which does not fit in AL | 00000H |
| 1 | Single step | after each instruction when the trap flag TF = 1 (debugging); TF is cleared during the ISR | 00004H |
| 2 | NMI | low-to-high edge on the NMI pin (e.g. power failure: save data) | 00008H |
| 3 | Breakpoint | the 1-byte instruction `INT 3` placed in a program; runs to the breakpoint then stops (debugging) | 0000CH |
| 4 | Overflow | `INTO` executed while OF = 1 (signed result too large) | 00010H |

**Priority** (highest first): divide error, INT n, INTO; then NMI; then INTR; then single step.
