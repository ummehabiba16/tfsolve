Write code to read all the bytes from EEPROM of an ATmega32, and if the byte stands for a character of capital letter, replace it with the corresponding small letter. For example, say a byte that you have read is 'B'. Then, you need to replace it with 'b'. However, say the byte that you have read is 'd'. Then, keep it unchanged.
