Suppose you have to design a new version of 80386 microprocessor that uses a 3-level paging mechanism. It will support up to 4GB of memory with a fixed page size of 16KB.

Moreover, you want the page tables at each level to have twice the number of entries as those of its previous level.

Now answer the following questions.

i) What is the total number of pages?

ii) How can you parse the 32-bit linear address received from segmentation unit? Show the splits with a figure. (Note that, the figure to explain the whole paging mechanism is not required here.)

iii) How many entries will there be in level 1, 2, 3 page tables?

You **must** show the calculations necessary.
