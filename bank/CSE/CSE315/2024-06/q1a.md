Assume that a microprocessor has an Address bus of 28-bit, a Data bus of 20-bit and the control bus of 4-bit. The primary memory is word (1 word = 2 byte) addressable.

There are in total 6 segment registers in the microprocessor. The longest supported instructions size is 10 bytes. The processor also supports virtual memory (Paging not supported). It needs 3 bits as access control bits in virtual memory mode. Now answer the following with proper justification.

i) Calculate the percentage of the memory that cannot be accessed using the segment offset pair.

ii) Calculate the optimal paragraph size.

iii) Calculate the total size of the shadow registers for the segment registers.

iv) Calculate the size of the virtual memory.
