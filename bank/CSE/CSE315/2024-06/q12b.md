Suppose, your friend wants to use the TIMER 1 overflow interrupt in ATMega32 to measure the time in takes to run a piece of code. The system clock frequency is set a 1 MHz. The prescaler is set to 64. To accomplish this task, she has written the C code mentioned in Listing 2. It determines the measured time in microseconds and stores it in the `elapsed_time` variable. Can you identify any issues in this code? Kindly mention these issues (If any) and briefly justify your answer.

**Listing 2: C program for question 12(b)**

```c
#include <avr/io.h>
#include <avr/interrupt.h>
#include <inttypes.h>

uint32_t overflow_count;

int main(void)  {
    uint32_t elapsed_time;

    TCCR1A = 0b00000010;
    TCCR1B = 0b00000001;
    TIMSK = 0b00000100;

    overflow_count = 0;
    TCNT1 = 0;

    int i, j;

    // we want to measure the runtime of the following codeblock
    //----start code----
    for(i=0; i<1000; i++)
        for(j=0; j<1000; j++)
            {;}
    //----end code------

    elapsed_time = overflow_count * 65536;

    return 0;
}
```
