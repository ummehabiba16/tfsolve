Suppose we want to generate two square waves using **only Timer 1** of ATMega32. The duty cycle of both waves is 50% and the frequency is 12.5 Hz. The phase difference between the two signals is 45 degrees. In other words, one wave lags the other one by $\frac{1}{8}$-th or one-eight of their full period. Explain which timer mode would be the most appropriate. Draw any appropriate diagrams, mention the value(s) of all the appropriate register(s). You need not write any C code but you need to mention all the relevant registers and their values. Note that you can only use timer 1, not timer 0 or 2.
