The C code in Listing 3 is an example of writing to the EEPROM of ATMega32. Answer the following questions based on the provided code.

(i) Which specific scenario will cause the code to not write anything to the EEPROM? How can we avoid that scenario?

(ii) Writing to an EEPROM is comparatively more expensive than reading. As a result, we want to check the data beforehand. If the data to be written is the same as the data already in the EEPROM, we can avoid writing anything. Make necessary modifications in the code to accommodate this task.

**Listing 3: C program for question 12(b)**

```c
void EEPROM_write(unsigned int uiAddr, unsigned char ucData)
{
    /* Wait for completion of previous write */
    while(EECR & (1<<EEWE))
    ;
    /* Set up address and data registers */
    EEAR = uiAddr;
    EEDR = ucData;
    /* Write logical one to EEMWE */
    EECR |= (1<<EEMWE);
    /* Start eeprom write by setting EEWE */
    EECR |= (1<<EEWE);
}
```
