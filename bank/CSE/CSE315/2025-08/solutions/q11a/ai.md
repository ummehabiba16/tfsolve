Assumptions: P uses PB4 ($\overline{SS}$, configured as output) to select Q and PB3 (any free pin) to select R. All three share a common ground and supply.

```text
          P (Master)                        Q (Slave)
     +----------------+               +----------------+
     | PB5 (MOSI) o---+------+------->| PB5 (MOSI)     |
     | PB6 (MISO) <---+---+--|--------| PB6 (MISO)     |
     | PB7 (SCK)  o---+-+-|--|------->| PB7 (SCK)      |
     | PB4 (SS)   o---+-|-|--|------->| PB4 (SS)       |
     | PB3        o-+ | | |  |        +----------------+
     +--------------|-+ | |  |
                    |   | |  |              R (Slave)
                    |   | |  |        +----------------+
                    |   | |  +------->| PB5 (MOSI)     |
                    |   | +-----------| PB6 (MISO)     |
                    |   +------------>| PB7 (SCK)      |
                    +---------------->| PB4 (SS)       |
                                      +----------------+
```

- **MOSI** (PB5): master out, slave in. Shared by all.
- **MISO** (PB6): slave out, master in. Shared; only the selected slave drives it.
- **SCK** (PB7): clock generated by the master. Shared.
- **$\overline{SS}$**: one line per slave. A slave is active only while its $\overline{SS}$ is low.
