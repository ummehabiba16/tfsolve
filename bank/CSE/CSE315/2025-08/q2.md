Assume that a 20-bit microprocessor has an address bus of 28 bits, a data bus of 20 bits, and a control bus of 24 bits. The primary memory is byte-addressable.

There are a total of six segment registers in the microprocessor. Each segment register contains 16 bits. The maximum supported instruction size is 10 bytes. The processor operates in two modes: Real Mode and Protected Mode (paging is also supported). It uses 3 bits as access control bits in virtual memory mode.

Now, analyze the following with proper justification:

i) What percentage of physical memory cannot be accessed in Real Mode?

ii) If the Page Directory and Page Table each contain 1K entries, what will be the page size?

iii) Calculate the total virtual memory size for the given microprocessor.

iv) Calculate the size of the Pre-fetch queue.
