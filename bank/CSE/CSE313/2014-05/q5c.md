In the aging algorithm, for page replacement, 8 bits are used for maintaining the counter corresponding to each page. Initially all the counters are set to zero. Let there are six page frames in the physical memory numbered from 0 to 5. After the first clock tick the R bits for pages 0 to 5 have the values 101011 (page 0 is 1, page 1 is 0, page 2 is 1, etc.). At subsequent clock ticks the R bit values are 110010, 110101, and 100010. Give the values of the counters after each tick. Which page will be replaced if a replacement is required after the last tick? (8+2=10)
