Alice has implemented a file system where each inode contains 6 direct pointers, 2 single indirect pointers, and 5 double indirect pointers. Given a disk size of 16 TB with 4 KB blocks, calculate the maximum size of a file that can be managed using this file system. Assume that the indirect pointer blocks are fully utilized, holding the maximum possible number of block addresses.
