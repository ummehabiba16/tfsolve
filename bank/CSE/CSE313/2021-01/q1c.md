A small computer on a smart card has four page frames. At the first clock tick, the R (reference) bits are 0111 (page 0 is 0, the rest are 1). At subsequent clock ticks, the values are 0010, 1010, 1100, 1011, 1010, 1101, and 0001. If the aging algorithm is used with an 8-bit counter, give the values of the four counters after the last tick. If a page has to be replaced now, which page will be selected. (8+2)
