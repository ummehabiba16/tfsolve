**Dynamic relocation (base & bounds).** Each process is given exactly one contiguous region of physical memory. Two hardware registers, `base` and `bounds`, are set by the OS on a context switch. Every virtual address generated by the CPU is translated and checked purely in hardware:

```text
if (virtual_addr >= bounds)
    raise_fault();   // protection: out-of-range access
else
    physical_addr = virtual_addr + base;   // relocation
```

This gives protection (a process cannot address memory outside its own region) and relocation (the OS can place/move the process anywhere in physical memory just by changing `base`), but the whole address space (code+heap+stack) must be one contiguous slab, so unused space between the heap and the stack is wasted (internal fragmentation of the address space).

**Segmentation.** Instead of one base/bounds pair, the MMU keeps several (e.g., one each for code, heap, stack). The top few bits of the virtual address select a segment; the rest is the offset within it:

```text
seg     = (virtual_addr) >> SEG_SHIFT;
offset = (virtual_addr) & OFFSET_MASK;
if (offset >= bounds[seg])
    raise_fault();
physical_addr = base[seg] + offset;
```

Because each logical segment has its own base/bounds, segments can grow/shrink independently and unused space between them is never allocated -- this eliminates the internal fragmentation problem of plain base-and-bounds. Segmentation also naturally supports sharing (e.g., a read-only code segment shared by many processes) and per-segment protection bits (read/write/execute).

**Which to choose?** Plain dynamic relocation is simpler (a single register pair) and is adequate only when the whole address space is small/densely used. Segmentation is preferred whenever the address space is *sparse* (large gaps between code, heap and stack, as is typical) because it avoids wasting physical memory on those gaps and enables sharing; its cost is slightly more complex hardware (multiple base/bounds pairs, a segment-selection step) and it still suffers external fragmentation of physical memory as differently-sized segments come and go.
