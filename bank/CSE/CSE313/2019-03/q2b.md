A computer has four-page frames. The time of loading, time of last access, and the R and M bits for each page are as shown below (the times are in clock ticks):

| Page | Time of loading | Last ref. | R | M |
|:-:|:-:|:-:|:-:|:-:|
| 0 | 230 | 265 | 0 | 1 |
| 1 | 140 | 270 | 0 | 0 |
| 2 | 110 | 285 | 1 | 1 |
| 3 | 126 | 280 | 1 | 0 |

i. Which page will NRU algorithm replace?

ii. Which page will FIFO algorithm replace?

iii. Which page will LRU algorithm replace?

iv. Which page will second chance algorithm replace?
