Suppose, the current Knowledge Base (KB) of a logical agent contains the following sentences:

(i) $P \lor R$

(ii) $R \Rightarrow Q$

(iii) $P \Rightarrow T$

(iv) $\neg S$

(v) $T \Rightarrow S$

Use PL-Resolution algorithm to determine whether the KB entails "Q" or not. Clearly show the set of clauses derived after each iteration of the algorithm.
