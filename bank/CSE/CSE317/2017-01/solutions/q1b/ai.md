**Computer engineering: "How can we build an efficient computer?"** For AI to succeed we need intelligence *and* an artifact to run it on. The computer has been the artifact of choice.

- **Hardware history:** the first operational computer was Turing's electromechanical *Heath Robinson* (1940), built to decipher German messages, followed by the electronic *Colossus* (1943). Zuse's *Z-3* (1941) was the first programmable computer, and the *ABC* and *ENIAC* followed in the US. Since then, performance has doubled roughly every 18 months (Moore's law). Today, massive parallelism (multicore, GPUs, TPUs, clusters) makes modern machine learning and large-scale search possible.
- **Software side:** operating systems, programming languages and tools are needed to write large AI programs.
- **Two-way influence:** AI demands fast hardware and big memory (search, deep learning, large models). Work in AI also pioneered many ideas that later became standard in computer science: time sharing, interactive interpreters, personal computers with windows and mice, rapid development environments, the linked-list data type, automatic storage management (garbage collection), and key concepts of symbolic, functional, declarative and object-oriented programming.
