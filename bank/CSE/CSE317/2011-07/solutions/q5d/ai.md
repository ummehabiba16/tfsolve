**Consistent (monotone) heuristic.** $h$ is consistent if, for every node $n$ and every successor $n'$ generated by an action $a$,

$$h(n)\le c(n,a,n')+h(n'),$$

and $h(G)=0$ for goals. This is a triangle inequality. Every consistent heuristic is also admissible.

**Theorem.** A\* using GRAPH-SEARCH, which never re-expands a state, is optimal if $h$ is consistent.

**Proof.**

1. **$f$ is non-decreasing along any path.** If $n'$ is a successor of $n$:

$$f(n')=g(n')+h(n')=g(n)+c(n,a,n')+h(n')\ \ge\ g(n)+h(n)=f(n).$$

2. **When A\* selects a node $n$ for expansion, the optimal path to $n$ has been found.** Suppose not. Then, by the graph-separation property, some node $n'$ on the optimal path from the start to $n$ is in the frontier. By step 1, $f(n')\le f(n)$ along that optimal path, and in fact $f(n')<$ the $f$ of the suboptimal copy of $n$, since $g$ is smaller. So $n'$ would have been selected before $n$. Contradiction.
3. From steps 1 and 2, the sequence of nodes expanded by graph search has **non-decreasing $f$**. The first goal node $G$ selected for expansion has $f(G)=g(G)$ (since $h(G)=0$), and every other goal reached later has $f\ge g(G)$. By step 2, $g(G)$ is the optimal cost to reach $G$. So the first goal expanded is an **optimal solution**.

(As a consequence, A\* expands all nodes with $f(n)<C^*$, some with $f(n)=C^*$, and none with $f(n)>C^*$.)
