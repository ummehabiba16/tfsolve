**Search tree.** The tree generated while searching for a solution. Its **root** is the node containing the initial state. Each **branch** is an action, and each node corresponds to the state reached by the **action sequence (path)** from the root. Expanding a node generates its children (successors). The set of generated but unexpanded leaves is the **frontier**. The search strategy decides which frontier node to expand next.

**Can several nodes correspond to the same state? Yes.** A node represents a *path*, and the same state can be reached by different paths, or by loops.

*Example* (Romania): $Arad\to Sibiu\to Arad$ creates a second node containing $Arad$. In the 8-puzzle, the same configuration can be reached by different move sequences.

Because of such **repeated states**, the search tree can be much larger than the state space, even **infinite** for a finite state space with loops. That is why **graph search** keeps an **explored set** and does not add nodes whose states have already been expanded.
