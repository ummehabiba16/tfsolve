Consider a state space where the start state is number 1 and successor function for state n returns two states: numbers 2n and 2n+1. (3+7+3+7=20)

(i) Draw the portion of the state space for states 1 to 25.

(ii) Suppose the goal state is 19. List the order in which nodes will be visited for breadth-first search, depth-first search, depth-limited search with limit 4 and iterative deepening search.

(iii) Which of the search approach finds the goal state in least time?

(iv) How would bi-directional search work in this problem? What is the branching factor in each direction?
