A workshop contains $M$ identical machines and a single repair technician. Each machine functions for an exponentially distributed duration with rate $\lambda$, after which it breaks down and requires repair. The repair time is also exponentially distributed with rate $\mu$. The technician can repair only one machine at a time.

(i) Define a suitable state-space representation to model this system.

(ii) Derive the steady-state probabilities for each state of the system.

(iii) Compute the long-run expected number of machines that are out of service.

(iv) Determine the steady-state fraction of time that a particular machine is operational.
