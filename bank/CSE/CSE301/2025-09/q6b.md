A list contains $n$ elements labeled $e_1, e_2, \ldots, e_n$ initially in some fixed order. At each discrete time step, one element is requested. The $i$-th element is requested with probability $p_i$ (where $\sum_{i=1}^{n}p_i=1$), independently of previous requests. After an element is requested, it is moved to the front of the list, while the relative order of all other elements is preserved. Assume that this process has been running for a long time and has reached a steady-state distribution. Compute the expected position of the requested element.
