A certain letter is equally likely to be in any one of three different files. Let, $\alpha_i$ be the probability that you will find the letter upon making a quick examination of file $i$, if the letter is, in fact, in file $i$, $i=1,2,3$. Given $\alpha_1=1/4$, $\alpha_2=1/3$, $\alpha_3=1/2$. Suppose you look into file 1 and do not find the letter after quick examination. Calculate the probability that the letter is in file 2 or file 3?
